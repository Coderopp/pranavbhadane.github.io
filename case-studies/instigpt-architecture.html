Project Overview

InstiGPT is a campus-wide AI chatbot built using Retrieval-Augmented Generation (RAG) architecture to help students access institutional knowledge instantly.

The Problem

IIT Kharagpur students faced significant friction when trying to find information about:

  • Academic policies and procedures
  • Course registration and requirements
  • Campus facilities and services
  • Administrative processes and deadlines

Information was scattered across multiple websites, PDFs, and portals with no unified search experience.

Technical Architecture

We designed a multi-layer architecture optimized for accuracy and speed:

  1. Document Processing Layer — PDF parsing, chunking, and metadata extraction
  2. Embedding Layer — ColPali multimodal embeddings for text and images
  3. Vector Store — Qdrant for efficient similarity search
  4. LLM Generation — Groq-hosted models for fast inference
"The best interface is no interface. Students should get answers, not links to documents."

Key Technical Decisions

  • Chose multimodal embeddings to handle diagrams and charts in academic PDFs
  • Implemented hybrid search (semantic + keyword) for better recall
  • Built a feedback loop to continuously improve answer quality
  • Deployed on cloud with auto-scaling for peak usage periods

Key Learnings

  • RAG systems require careful chunking strategies for optimal retrieval
  • User feedback is essential for identifying edge cases
  • Latency matters — users expect near-instant responses
  • Multimodal support dramatically improves answer quality for technical content
